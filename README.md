# Paw Rivals 🐱🆚🐶

Animated **Cat vs Dog** YouTube Shorts: the same situation, two very different reactions.
Split screen: the cat reacts on top, the dog below, and the video ends with "Team cat or team dog? Comment 1 or 2!".

Everything is generated by code (characters, rooms, music and sound effects), so there are no copyrighted assets.
The rendering helpers come from the Bloop Bonkers engine.

- `paws.py`: the video engine, built from `src/` by `./build.sh`. Edit the files in `src/`, not `paws.py`.
- `run.py`: picks a plan (cat, dog, room, 4 situations; repeats are avoided and better-performing situations are weighted up), renders it, uploads it and logs it to `history.json`.
- `tools/sheet.py`: preview contact sheets for checking every situation.
- `.github/workflows/videos.yml`: 3 Shorts a day (14:00, 18:00, 23:00 UTC), but only once the YouTube secrets exist.
- `.github/workflows/comments.yml`: posts a first comment on new videos and replies to comments every hour.

Preview locally: `python paws.py --preview 3,7 --gags doorbell,vacuum --cat ginger --dog goldie`
